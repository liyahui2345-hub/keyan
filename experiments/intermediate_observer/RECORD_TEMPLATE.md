# 中间观测器实验记录模板

[返回入口](../../papers/intermediate_observer/README.md)

复制本文件为独立的 EXP-日期-编号.md；不要覆盖通用 TEMPLATE.md 或 WLS 的 BASELINE.md。
默认状态：**未运行**。空白或“待填写”不是成功结果。

## 追溯信息

- 实验 ID / 日期 / 执行人：
- 论文 ID、标题、版本 / 目标图表 T-* / 算例：
- 实验类型：原文复现 / 自设探索 / 消融（待选）：
- 代码完整 Git SHA、分支、工作区是否有未提交修改及补丁位置：
- 参数表版本、最终配置文件路径与 SHA256：
- 系统、Python、依赖锁定版本、求解器与积分器版本：
- 数据 URL、获取日期、许可、文件 SHA256、预处理：
- 原始方程 F-*、适用假设 A-*、未满足或未核对项：
- 完整运行命令及工作目录：待实现后填写，不提供虚构命令。
- 随机源、种子、重复次数或确定性说明：
- 真值/估计/内部初值、输入事件、时间范围、步长与容差：
- 与论文的不同设置、来源及影响：

## 运行前验收计划

- 目标曲线和参考数据：
- 指标定义、单位、评价窗口、时间对齐方法：
- 预先确定的验收阈值、依据和记录日期：
- 增益可行性、假设、维度及单点校验计划：
- 数值敏感性检查方案（步长减半或容差收紧）：

- 开始/结束时间、退出码、运行耗时：
- 标准输出/错误日志、警告与求解器状态：
- 实际运行状态：未运行 / 成功执行 / 失败 / 中止（待选）：
- 原始轨迹、配置快照、指标和图表路径及 SHA256：
- 建议本地产物目录：results/intermediate_observer/<experiment-id>/（被 Git 忽略）。

## 差异、失败及结论

- 原文结论（注明页码；待原文核对）：
- 本次观察（仅根据实际产物；未运行）：
- 差异可能原因及支持证据（区分推测与已验证）：
- 数值敏感性检查结果：
- 失败原因、失败配置和日志位置（失败也必须保留）：
