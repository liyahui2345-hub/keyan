## 填写顺序

1. [论文索引](../INDEX.md)：锁定标题、DOI、版本及一个目标算例。
2. [模型与假设](MODEL_ASSUMPTIONS.md)：列清可测信息、未知量、维度及理论适用条件。
3. [公式到代码映射](EQUATION_CODE_MAP.md)：核对中间变量定义、观测器更新、未知输入重构及增益设计。
4. [参数表](../../experiments/intermediate_observer/PARAMETERS.md)：补齐数值、单位和来源。
5. [目标图表](../../experiments/intermediate_observer/TARGETS.md)：指定论文图号、比较口径和验收阈值。
6. 复制 [实验记录模板](../../experiments/intermediate_observer/RECORD_TEMPLATE.md) 为独立记录，实施后记录真实结果。

所有模板中的 ID 是仓库内部标识，不是论文中的编号。论文没说明的项目写“原文未报告”，自设项目写“自设”并说明影响；不适用项目须写依据，不能静默填 0。

## 下一步实现所缺的具体输入

| 优先级 | 必需输入 | 完整性判据 / 填写位置 |
| --- | --- | --- |
| P0 | 目标论文标题、DOI或可靠链接、可阅读的确定版本及补充材料 | 能定位全部方程、假设和仿真页码；论文索引 |
| P0 | 系统动力学、输出方程、变量顺序、维度、单位、子系统及耦合（如适用） | 每个矩阵有完整数值或生成方法；模型表与参数表 |
| P0 | 中间变量定义、观测器全部更新式、状态与未知输入的重构式 | 公式无缺页，符号与求导关系一致；公式映射 |
| P0 | 增益数值或可执行的设计条件与求解流程 | 若使用 LMI，需完整约束、决策变量、求解器与可行性容差；不是所有论文都采用 LMI |
| P0 | 真值与观测器初值、控制输入、未知输入/攻击/故障的分段函数 | 起止时刻、幅值、通道及光滑性已知；参数表 |
| P0 | 时间范围、采样周期、积分设置、噪声和随机性设定 | 区分原文给定与自设；参数表 |
| P0 | 一个具体目标图号/表号、曲线含义及对应算例 | 坐标、单位、评价窗口、误差定义、对照值和验收口径；目标图表 |
| P1 | 原始曲线数据、作者代码及环境（若可得） | 记录获取位置/版本；若只能读图，注明数字化误差 |

拿到 P0 资料后，先核对维度与一个时刻的导数/重构值，再实施单算例仿真。资料不足时只能进行明确标注的自设探索，不能声称完成原论文复现。
